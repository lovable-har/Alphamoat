android

Install on Android / Build .APK

Package this app as a native Android APK

Because browsers cannot compile binary Android packages directly, you can either install this immediately as a fullscreen Android Web App or export the standalone HTML bundle to compile a signed .apk via Capacitor or PWABuilder.

Fastest Way to Compile a Real .APK:
1. Download index.html into a folder www/
2. npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
3. npx cap init AlphaMoat com.alphamoat.screener --web-dir=www
4. npx cap add android && npx cap sync
5. cd android && ./gradlew assembleDebug
→ Outputs app/build/outputs/apk/debug/app-debug.apk
